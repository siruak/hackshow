# hackshow— 黑客松作品统一收集与宣发平台

> 参赛者填一次信息，自动生成内容结构 + 风格页面；主办方一键收集所有作品，导出全部宣发物料。

## 项目简介

HackShow 是一个面向黑客松场景的作品收集与宣发工具。参赛者通过填写信息 + 魔药瓶风格定制，生成统一的宣传页；主办方后台统一收集所有作品，一键导出公众号推文、官网展示页、社交媒体九宫格、路演大屏轮播。

**核心价值：**
- 对参赛者：填一次信息，自动生成内容结构 + 风格页面，省掉开发之外的宣发成本
- 对主办方：统一格式收集所有作品，活动结束后一键生成全部宣发物料

## 功能特性

1. 设备自适应
手机端：三步独立页面（录入 → 定制 → 预览）
PC 端：三栏联动界面（预览 / 魔药定制 / 信息录入）
2. 信息录入 + 自动内容生成
必填项：项目名称、一句话介绍、至少 1 个技术栈标签
系统自动提炼副标题和 3-5 个功能亮点
支持团队成员、项目截图、外链（GitHub / 演示 / 视频）
3. 魔药瓶风格定制
6 种风格：技术 / 活力 / 高级 / 温暖 / 炫酷 / 未来
最多点选 5 次，可重复叠选
混合规则：主风格决定背景、字体、排版；其余风格混合决定圆角、阴影、按钮、点缀
支持重置、倾倒动画
4. 宣传页预览与导出
实时预览，边输入边更新
全屏查看
导出卡片（PNG 图片）
生成分享链接 + 二维码
5. 主办方后台
所有作品卡片式排列
按场次 / 状态 / 奖项筛选
一键导出：
公众号合集推文（HTML）
官网展示页（作品卡片网格）
社交媒体九宫格（3×3 拼图）
路演大屏轮播（10 秒自动翻页，键盘控制）

## 技术栈

前端：React 18 + TypeScript
构建：Vite 5
路由：React Router DOM 6
样式：Tailwind CSS 3（PostCSS + Autoprefixer）
图标：lucide-react
字体：Google Fonts
发布：静态站点，托管在 MonkeyCode-AI 作品集
页面在浏览器里跑，数据走 Supabase 的 hackathons / projects 表。
